# Amazon Clone
</br>
</br>
A simple **Amazon Clone** created using **HTML and CSS**. 
</br>
This project recreates the basic look and layout of Amazon's website for practice and learning purposes.<br>
The main goal of this project is to practice **HTML structure, CSS styling, Flexbox, layouts, navigation bars, product cards, and website design**.<br><br>

## Features
</br>
</br>
- Amazon-style navigation bar<br>
- Amazon logo<br>
- Search bar<br>
- Navigation menu<br>
- Hero/banner section<br>
- Product sections<br>
- Product cards with images<br>
- Multiple product categories<br>
- Amazon-inspired UI design<br>
- Footer section<br>
- Clean and simple webpage layout<br><br>
</br>
## Technologies Used
</br>
- **HTML5** – Used to create the structure and content of the website.<br>
- **CSS3** – Used to style the website, including colors, spacing, layouts, product cards, navigation bar, hero section, and footer.<br><br>
